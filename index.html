Science Hound is backed by a local server. Accounts, videos, and reviews are stored server-side (passwords are hashed, never stored in plain text), so everyone connecting to this server sees the same library, from any device. This is a basic local setup, not a hosted production service, so it only runs while the server is running. Reviews are automatically filtered for offensive language.
